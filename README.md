# homebrew-bitrise-build-cache

Homebrew tap for the [Bitrise Build Cache CLI](https://github.com/bitrise-io/bitrise-build-cache-cli).

## Install

```sh
brew install bitrise-io/bitrise-build-cache/bitrise-build-cache
```

Or tap first, then install:

```sh
brew tap bitrise-io/bitrise-build-cache
brew install bitrise-build-cache
```

## Update

```sh
brew update
brew upgrade bitrise-build-cache
```

## How this tap is maintained

The `Formula/bitrise-build-cache.rb` file is generated and pushed automatically by [GoReleaser](https://goreleaser.com/) on every release of `bitrise-io/bitrise-build-cache-cli`. Do not edit the formula manually — changes will be overwritten on the next release.

For issues with the CLI itself, please file them at https://github.com/bitrise-io/bitrise-build-cache-cli/issues.
